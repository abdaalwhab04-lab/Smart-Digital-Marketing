Smart Digital Marketing — Project Context

Project Name

Smart Digital Marketing

Main Goal

This project is a complete digital marketing platform that includes an intelligent DXN customer assistant, educational content, business opportunity information, and marketing tools.

Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git
- GitHub
- GitHub Pages

Main Components

DXN Auto Reply

An intelligent chatbot that answers customer questions about:

- DXN products
- Registration
- Business opportunity
- Shipping
- Support
- WhatsApp contact

Chat Engine

The chatbot uses a scoring engine to compare the user's question with the knowledge base and return the best answer.

Knowledge Sources

The chatbot can load answers from:

- questions.json
- Google Sheets
- Local Storage

Development Rules

- Keep the project modular.
- Never rename files unless required.
- Keep backward compatibility.
- Do not remove existing features without user approval.
- All new features should integrate with the current architecture.

Deployment

The project is deployed using GitHub Pages.

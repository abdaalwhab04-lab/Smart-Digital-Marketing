How To Use With AI Tools

When using:

- Google AI Studio
- ChatGPT
- Gemini
- Other AI assistants

Provide the files in this folder first so the assistant understands:

- Project purpose.
- File structure.
- Development rules.
- Current status.

---

Project Principle

The AI assistant must help improve the project without breaking existing features.

Always prioritize:

1. Stability.
2. Security.
3. Clean code.
4. Easy maintenance.
5. Future expansion.

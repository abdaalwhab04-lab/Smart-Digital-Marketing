DXN Chatbot Admin Panel Documentation

Overview

The Admin Panel is a future component of Smart Digital Marketing.

Its purpose is to allow administrators to manage the chatbot without editing source code.

---

Main Features

Question Management

The administrator can:

- Add new questions.
- Edit existing questions.
- Delete questions.
- Search questions.

---

Answer Management

Each answer can include:

- Response text.
- Keywords.
- WhatsApp activation.
- Category.

---

Knowledge Base Management

The panel will support:

- Import questions from files.
- Export chatbot data.
- Synchronize with Google Sheets.
- Backup knowledge data.

---

User Management

Future features:

- Admin accounts.
- Permissions.
- Activity logs.

---

Analytics

The dashboard can display:

- Number of conversations.
- Most asked questions.
- Questions without answers.
- Customer interests.

---

Security

The Admin Panel must include:

- Authentication.
- Access control.
- Data protection.
- Secure configuration.

---

Future AI Features

Planned:

- AI suggestions for new answers.
- Automatic question classification.
- Learning from unanswered questions.
- Smart content improvement.

---

Development Principle

The Admin Panel should be modular and should not break the existing chatbot system.

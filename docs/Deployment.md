Smart Digital Marketing — Deployment Documentation

Overview

This document explains how to run, update, and deploy the Smart Digital Marketing project.

---

Local Development

The project can be opened locally using:

- Web browser.
- Local development server.

The chatbot works as a frontend application.

---

Project Update Process

When making changes:

1. Edit the required files.
2. Test the changes.
3. Check JavaScript syntax.
4. Commit changes using Git.
5. Push updates to GitHub.

Example:

git add .
git commit -m "Update chatbot features"
git push

---

GitHub Repository

The project source code is stored in GitHub.

Git is used for:

- Version control.
- Backup.
- Tracking changes.
- Restoring previous versions.

---

GitHub Pages Deployment

The website can be published using GitHub Pages.

Deployment steps:

1. Push changes to GitHub.
2. Enable GitHub Pages.
3. Select the correct branch.
4. Wait for the deployment process.

---

Testing Checklist

Before publishing:

- Check website loading.
- Check chatbot interface.
- Test sending messages.
- Verify answers.
- Check WhatsApp button.
- Check browser console for errors.
